Trilateration

Turns each RSSI into a distance with d = 10(−59 − RSSI)/(10·2.2), then solves the circle equations by linear least squares. A few dB of noise becomes metres of distance error, so it scatters badly.

Weighted centroid

Averages the beacon positions weighted by 1/d. Stable under noise but always pulled toward the middle of the beacons, so it can never reach the walls.

kNN fingerprinting

Offline: survey a 1 m grid (336 points, 10 samples each). Online: find the K = 4 grid points whose RSSI vectors are closest to the live reading and average them. Turn on "Radio map grid" to see the chosen neighbours.

kNN + Kalman (proposed)

Feeds each kNN fix into a constant-velocity Kalman filter with state [x, y, vx, vy], q = 0.05 and R = 2.5² m². The motion model rejects jumps a walking person cannot make.

Things to try in the demo

  1. Slide σ from 1 to 8 dB. Trilateration's mean error climbs fastest.
  2. Turn on distance circles. They rarely meet at one point, which is why trilateration fails.
  3. Switch to 3 beacons, then 8. kNN improves as beacons are added.
  4. Drag the user around. The green track follows smoothly while the blue dots jump.

The same model and parameters as the Python project (Ptx = −59 dBm, n = 2.2, radio map surveyed at σ = 4 dB, K = 4). This page uses a JavaScript random generator, so its numbers differ slightly from the official Python results in the README.
